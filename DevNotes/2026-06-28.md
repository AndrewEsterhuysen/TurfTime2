# Dev Notes - 2026-06-28

## iPhone Deploy Reliability

### Finding
- In this environment, `dotnet ... -p:_DeviceName=:v2:udid=<UDID>` could stall with:
  - `Please connect the device ':v2:udid=...'`
- Deploying by CoreDevice name worked reliably and launched successfully.

### Working command pattern
```bash
dotnet build TurfTime2.csproj -f net10.0-ios -c Debug -p:RuntimeIdentifier=ios-arm64
dotnet build TurfTime2.csproj -t:Run -f net10.0-ios -c Debug -p:RuntimeIdentifier=ios-arm64 -p:_DeviceName=AndrewsiPhone
```

### Repo helper
- Added `deploy-ios-device.sh` at repo root.
- Default device name: `AndrewsiPhone`.
- Optional override:
  - `./deploy-ios-device.sh "<YourDeviceName>"`
