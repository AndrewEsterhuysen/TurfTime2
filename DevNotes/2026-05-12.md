# Dev Session — 2026-05-12

## Goal
Fix vertical drag-and-drop gesture delivery on Android. Drag was unresponsive unless the user first attempted a horizontal swipe.

## Root Cause
Android's `RecyclerView` (backing MAUI's `CollectionView`) intercepts vertical `MOVE` events before the MAUI pan recognizer fires. Child `TextView`/`Label` elements consumed `ACTION_DOWN`, so parent touch listeners added via `SetOnTouchListener` never received events.

## Solution
Replaced MAUI's default platform layout for `DragRow` with a custom native `LayoutViewGroup` subclass:

- **`DragLayoutViewGroup.cs`** — overrides `DispatchTouchEvent`; calls `RequestDisallowInterceptTouchEvent(true)` on `ACTION_DOWN`, preventing `RecyclerView` from claiming the touch stream before MAUI gesture logic runs.
- **`DragRowHandler.cs`** — Android `IViewHandler` for `DragRow`; returns `DragLayoutViewGroup` from `CreatePlatformView()` with `CrossPlatformLayout = VirtualView` intact.
- **`MauiProgram.cs`** — registers handler via `ConfigureMauiHandlers` under `#if ANDROID`.
