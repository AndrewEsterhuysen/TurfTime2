# Google Play Store Assets

## Required Assets for Play Store Listing

### 1. App Icon
- **512 x 512 px** PNG (32-bit)
- No transparency
- File: `icon_512x512.png`

### 2. Feature Graphic
- **1024 x 500 px** JPG or PNG
- File: `feature_graphic_1024x500.png`
- Showcases your app prominently

### 3. Screenshots (Required: at least 2)
- **Phone Screenshots**: Minimum 2, Maximum 8
  - Landscape: 1920x1080 or 2560x1440
  - Portrait: 1080x1920 or 1440x2560
- Save as: `screenshot_phone_01.png`, `screenshot_phone_02.png`, etc.

### 4. Privacy Policy
- Required for apps requesting permissions
- Must be hosted publicly (URL)
- Create: `privacy_policy.md` and host on GitHub Pages or website

### 5. App Description
**Title**: Turf Time - Soccer Rotation Manager (max 50 chars)

**Short Description** (max 80 chars):
Manage soccer team rotations with timers, fair play tracking, and game logs

**Full Description** (max 4000 chars):
Turf Time is the ultimate soccer team rotation manager for coaches managing youth soccer teams, fast fives, and recreational leagues.

**KEY FEATURES:**
⚽ Smart Player Rotation
- Automatic rotation scheduling for equal playing time
- Highlight next players to rotate
- Drag-and-drop to adjust rotation order
- Rotate 1 or multiple players at once

⏱️ Dual Timers
- Match timer with automatic half-time tracking
- Rotation countdown with visual/vibration alerts
- Auto-calculate optimal rotation intervals
- Click timers to customize durations

📊 Position Management
- Field, Bench, Goalie, and Inactive tracking
- Color-coded player status
- Individual playing time counters
- One-goalie enforcement

📱 Display Modes
- View 1 (Standard): Full roster view
- View 2 (Zoomed): Hides inactive players
- View 3 (Minimal): Shows only rotating players

📋 Game Logger
- Automatic event tracking
- Export game data to CSV
- Share game summaries
- Review past sessions

🔧 Advanced Features
- Screen stays on during matches
- Persistent data between sessions
- Fast fives optimization (40-min matches)
- Traditional match support (90-min)
- Vibration alerts for rotations

**PERFECT FOR:**
- Youth soccer coaches
- Fast fives leagues
- Recreational teams
- Indoor soccer
- Small-sided games
- Parent coaches

**NO ADS. NO SUBSCRIPTIONS. FREE FOREVER.**

Created by a coach, for coaches who want fair playing time and stress-free substitutions.
